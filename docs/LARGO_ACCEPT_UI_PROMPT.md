# Largo Accept — UI

Краткое описание интерфейса (актуально для текущего дизайна).

- Окно ~280×164, frameless, не ресайзится. Тёмная CRM-эстетика в духе Cursor.
- Titlebar 36px: рыжий знак (`public/brand.png`, исходник `public/logo.svg`) + `Largo Accept` в JetBrains Mono, справа свернуть/закрыть (кнопки 28px, иконки 16px).
- Главная зона: кнопка «Автопринятие» + бейдж F10.
  - Выкл: заливка `rgba(228,228,231,.8)`, тёмный текст.
  - Вкл: прозрачный фон, рыжий контур, рыжий F10.
- Под кнопкой строка статуса: лампа + моно-подпись (`// ищу ready-check`, `// принимаю…`, `// матч принят`, `// dota не запущена`, `// dota свёрнута`).
- Токены: фон `#0f0f0f`, границы `#27272a`, текст `#f4f4f5`, приглушённый `#9a9aa2`, акцент `#f0883e`, предупреждение `#c4a574`, опасность `#ff6b6b`. Радиусы 6/8px. Шрифты Inter + JetBrains Mono.
- Иконка приложения и ярлыка генерируется `npm run prepare:brand` (`scripts/make-icon.js`): знак ~88% холста + лёгкое рыжее свечение.
